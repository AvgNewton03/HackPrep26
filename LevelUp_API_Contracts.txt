# LevelUp Network Communication Architecture (API Contracts)

## 1. Generate Lesson & Quiz Content
Endpoint: POST /api/lessons/generate
Purpose: Takes the user's selected topic, triggers the LLM on the backend, and returns the lesson and quiz questions.

### Request Payload
```json
{
  "topic": "React Hooks",
  "difficulty": "beginner",
  "isDailyChallenge": false
}
```

### Response Payload
```json
{
  "success": true,
  "data": {
    "lessonId": "lsn_987654321",
    "topic": "React Hooks",
    "lessonContent": "React Hooks are functions that let you 'hook into' React state and lifecycle features from function components...",
    "quiz": [
      {
        "questionId": "q_101",
        "question": "Which hook is used to manage side effects?",
        "options": [
          { "optionId": "opt_a", "text": "useState" },
          { "optionId": "opt_b", "text": "useEffect" },
          { "optionId": "opt_c", "text": "useContext" },
          { "optionId": "opt_d", "text": "useReducer" }
        ]
      }
    ]
  }
}
```

## 2. Submit Quiz & Calculate Gamification
Endpoint: POST /api/quiz/submit
Purpose: Validates the user's answers on the server, calculates XP, updates streaks, checks for level-ups/badges, and returns the results.

### Request Payload
```json
{
  "lessonId": "lsn_987654321",
  "answers": [
    { "questionId": "q_101", "selectedOptionId": "opt_b" },
    { "questionId": "q_102", "selectedOptionId": "opt_a" }
  ],
  "timeTakenSeconds": 45
}
```

### Response Payload
```json
{
  "success": true,
  "data": {
    "score": 4,
    "totalQuestions": 5,
    "results": [
      {
        "questionId": "q_101",
        "isCorrect": true,
        "correctOptionId": "opt_b"
      },
      {
        "questionId": "q_102",
        "isCorrect": false,
        "correctOptionId": "opt_c"
      }
    ],
    "gamificationUpdates": {
      "xpGained": 40,
      "totalXp": 1240,
      "currentLevel": 5,
      "levelUpTriggered": true,
      "streak": {
        "currentStreak": 7,
        "streakMaintained": true
      },
      "newBadges": [
        {
          "badgeId": "bdg_005",
          "name": "7-Day Scholar",
          "iconUrl": "/badges/7-day-streak.png",
          "description": "Maintained a learning streak for 7 consecutive days!"
        }
      ]
    },
    "nextRecommendedDifficulty": "intermediate"
  }
}
```

## 3. LLM "Explain Why I'm Wrong" (Bonus)
Endpoint: POST /api/quiz/explain
Purpose: If the user gets a question wrong, they can click "Explain this", which prompts the LLM to explain the misconception.

### Request Payload
```json
{
  "lessonId": "lsn_987654321",
  "questionId": "q_102",
  "userSelectedOptionId": "opt_a"
}
```

### Response Payload
```json
{
  "success": true,
  "data": {
    "explanation": "You selected 'useState', but 'useState' is only for managing local state. The correct answer is 'useEffect' because fetching data from an external API is considered a side effect, which must be handled after the component renders."
  }
}
```
